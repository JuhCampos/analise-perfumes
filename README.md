# Análise Exploratória de Dados: Mercado Global de Perfumaria

Estudo analítico desenvolvido em Python para investigar padrões de votação, distribuição de notas e anomalias de engajamento no setor de perfumaria a partir de dados históricos do Kaggle.

---

## Objetivos do Estudo

* **Mapeamento de Mercado:** Avaliação da concentração de participação de mercado por grandes holdings e conglomerados globais.
* **Oportunidades de Portfólio:** Identificação de nichos com alta satisfação do consumidor para estratégias de diferenciação.
* **Tratamento de Anomalias:** Investigação do impacto de *review bombing* e distorções na percepção de valor dos produtos.

---

## Tecnologias e Bibliotecas

* **Linguagem:** Python
* **Tratamento de Dados:** Pandas, NumPy
* **Visualização:** Seaborn, Matplotlib, Plotly
* **Ambiente:** Jupyter Notebook

---

## Estrutura do Repositório

* `analise_perfumes_v3.ipynb`: Notebook com o pipeline analítico e código fonte.
* `fra_cleaned.csv`: Base de dados tratada após limpeza e estruturação.
* `Projeto_Analise_Perfumes_Kaggle.pdf`: Apresentação executiva com a síntese visual dos resultados.
